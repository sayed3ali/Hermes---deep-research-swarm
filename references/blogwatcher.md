## Role in Deep Research Swarm

Supplementary monitoring skill for deep-research-swarm. Use when the research requires tracking ongoing narratives from blogs, RSS, or Atom feeds.

## Trigger within this workflow

- The topic is fast-moving (e.g., tech industry, policy debate, emerging controversy).
- Primary sources include company blogs, newsletters, think-tank publications, or independent analysts.
- User asks for "latest developments" or "what are people saying".

## How to use it from deep-research-swarm

1. Load the skill (`skill_view(name='blogwatcher')`) for feed-monitoring guidance.
2. Use it to monitor specific blogs or RSS feeds relevant to the dimension under investigation.
3. Incorporate findings into the appropriate `{topic}_dim{NN}.md` file with proper `[^id]` citations.

## When NOT to use

- Not a replacement for broad web search in Phase 1.
- Use only when feed-based sources are known to be high-value for the topic.
