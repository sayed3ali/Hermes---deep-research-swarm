## Role in Deep Research Swarm

Supplementary research skill for deep-research-swarm. Use when the topic has an academic or scientific dimension and peer-reviewed preprints would strengthen the evidence base.

## Trigger within this workflow

- Phase 1 (Landscape Scan) or Phase 3 (Parallel Deep Dive) identifies a need for academic papers.
- The topic involves scientific claims, technical methods, or literature-review gaps.
- User explicitly asks for academic sources.

## How to use it from deep-research-swarm

1. Load the skill (`skill_view(name='arxiv')`) for search syntax and download guidance.
2. Use it to search arXiv by keyword, author, category, or ID.
3. Feed relevant paper abstracts, PDFs, or BibTeX entries into the dimension files as evidence.
4. Cite arXiv papers using `[^id]: Author. Title. arXiv:ID. URL` format.

## Free Academic Source Context

arXiv is one of many free academic sources. For comprehensive academic research, also consult:

- **CORE** (core.ac.uk) — 200M+ open access papers across all disciplines
- **OpenAlex** (openalex.org) — 250M+ works with open API
- **Semantic Scholar** (semanticscholar.org) — AI-enhanced academic search
- **PubMed Central** (pmc.ncbi.nlm.nih.gov) — Biomedical and life sciences
- **bioRxiv/medRxiv** — Biology and medicine preprints
- **SSRN** — Social sciences preprints

See `references/free-academic-sources.md` for the complete guide to free academic sources.

## When NOT to use

- Do not default to arXiv for every query. Most deep-research topics need a broader web search first.
- Use arXiv as a targeted supplement, not a replacement for general landscape scanning.
